# Architecture Decision Records (ADR)

This directory documents key architectural and engineering decisions made during the evolution of **Rentify Frontend**.

## What is an ADR?

An Architecture Decision Record (ADR) captures an important architectural choice, along with its context, considered alternatives, rationale, and consequences (both positive and negative). We follow the **Michael Nygard format**.
